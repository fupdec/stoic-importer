# Security and privacy

Do not attach personal backups or diary content to public issues. Report security
problems privately to the repository maintainer through GitHub private vulnerability
reporting when enabled; otherwise request a private contact without posting details.
There is no hosted service, telemetry or remote diary processing.

Archives are untrusted input. JSON expansion and member counts are bounded; paths,
symlinks and duplicate IDs are rejected. Diagnostics exclude diary content.
Intermediate exports contain sensitive plain text. The app does not encrypt them.
The input archive is never deleted or changed. Test with synthetic fixtures only.
