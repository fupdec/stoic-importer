# Stoic Importer

Локальное приложение для переноса записей из Stoic в Apple «Дневник».
[English](README.md) · [Скачать](https://github.com/fupdec/stoic-importer/releases)

Откройте исходный ZIP Stoic, проверьте текст и фотографии, затем перенесите
выбранные записи или поставьте все доступные в очередь. Сохраняются исходные даты
и несколько фотографий. Локальный реестр блокирует автоматические повторы.
Исходный архив не изменяется. Нет AI, аналитики и обработки дневника нашим сервером.

## Установка

**Предварительная версия для Mac с Apple silicon.** Автор подтвердил массовый
импорт с фотографиями на своём Mac; другие устройства пока не проверены.
Для записи нужны Apple «Дневник» и совместимое действие «Команд» — macOS 26+.
Проверки выполнялись на macOS 27. Для просмотра архива целевая версия — macOS 14+.

1. Скачайте ZIP приложения и `StoicMacWriterV3.shortcut` из
   [Releases](https://github.com/fupdec/stoic-importer/releases).
2. Распакуйте ZIP и перенесите `StoicImporter.app` в «Программы».
3. Откройте приложение. У этой версии **локальная ad-hoc подпись, без Developer ID
   и нотариализации Apple**. Если macOS заблокирует первый запуск и вы доверяете
   загрузке: **Системные настройки → Конфиденциальность и безопасность →
   Всё равно открыть**, затем подтвердите запуск.
   [Инструкция Apple](https://support.apple.com/ru-ru/102445).
4. Установите команду под именем **StoicMacWriterV3** и выберите её в приложении.
   **Некоторые Mac отклоняют команду Дневника как несовместимую.** Ранее
   использовалась установка через iPhone и синхронизация команд через iCloud,
   но для других устройств эта сборка не проверена. Если установка не удалась,
   не начинайте перенос.
5. Откройте ZIP Stoic. Сначала перенесите одну проверенную запись и проверьте
   текст, дату и все фотографии в «Дневнике», затем запускайте очередь.

[Подробная инструкция и ограничения](docs/installation.md).

## Ограничения

- Возврат команды без ошибки не гарантирует сохранение. После прерывания сначала
  проверьте результат в «Дневнике», затем решайте, нужен ли повтор.
- Старые и ручные импорты автоматически не обнаруживаются. Существующие записи
  не редактируются. Повтор может создать дубли; удаление записи не удаляет реестр.
- Перенос геометок **не включён**; экспериментальная подготовка есть в исходниках.
- Не прикладывайте личные ZIP, предпросмотры и локальные данные к публичным issues.
- Проект не связан со Stoic или Apple.

## Сборка

Нужны Xcode 26+ с macOS SDK, Swift 6 и Python 3. Готовой Intel-сборки нет.

```sh
./scripts/test.sh
python3 -m unittest discover -s Tests/ShortcutTests
./scripts/build_mac_app.sh
open dist/StoicImporter.app
```

Скрипт создаёт release-сборку и ставит ad-hoc подпись, без нотариализации.
